# hausakte-nt

Buyer's due-diligence dossiers — line-by-line readings of German property document packages (Grundbuch, Teilungserklärung, Wirtschaftsplan, HOA minutes, energy certificate, etc.), surfacing hard-to-spot risks and an evidence-based negotiation case.

Published via GitHub Pages: **https://nithinkumarant.github.io/hausakte-nt/**

## Structure

```
index.html              → Pleidelsheimer Str. 3 (EN)
es/index.html           → Pleidelsheimer Str. 3 (ES)
bauhofstrasse-9/index.html      → Bauhofstraße 9 (EN)
bauhofstrasse-9/es/index.html   → Bauhofstraße 9 (ES)

loechlesaecker-21/es/index.html → Löchlesäcker 21 (ES)

financing-options/index.html    → Financing & cost-of-ownership calculator (generic tool)
```

Each dossier is a self-contained HTML file with an `EN · ES` language toggle.

---

> These dossiers are document-based negotiation aids, not certified valuations (Verkehrswertgutachten) or legal/tax advice. Have the purchase contract and Grundbuch reviewed by a Notar, and the building inspected by a Bausachverständiger, before signing.
